# my_arch
Collection of dot files for ArchLinux with Hyprland, vim and zsh.

You can install packages, copy configuration files, etc. with this command:

# Direct Installation

```
bash <(curl -s https://raw.githubusercontent.com/STERN3L/my_arch/refs/heads/main/install_arch_hyprland.sh)
```

# Manually Installation

```
https://github.com/STERN3L/my_arch.git
```

```
cd /my_arch
chmod +x install_arch_hyprland.sh
./install_arch_hyprland.sh
```
